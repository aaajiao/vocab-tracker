## 部署检查发现并修复

- 普通 Vercel Function 不按 Next.js 的 catch-all 方式处理多级路径；使用显式 rewrite，将版本化 API 映射到统一函数入口。
- 本地 Bun 能解析无扩展名导入，部署的 Node ESM 需要 `.js` 扩展名；修正后已验证编译产物可加载及生产调用成功。
- 固定 Vercel 的 Bun 安装/构建命令和 packageManager，避免平台生成的其他锁文件改变依赖解析。

## 仍需真人体验

Codex 实时语音的真实听说、打断、发音听辨及延迟，需要用户开启麦克风参与一轮练习。本次未将文字或HTTP测试当作语音验收。

## 平台检查备注

四张学习表启用RLS且不给客户端任何表权限，只有已鉴权的服务端能访问；因此数据库检查器显示的“RLS enabled, no policy”是预期的关闭访问状态。平台另有既存的[泄漏密码保护未开启提示](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection)，此次没有改变账号的全局密码策略。

测试账号、词汇和待测凭据均与真实学习数据隔离；使用 `scripts/cleanup-learning-fixture.ts` 清理保留的浏览器夹具。
