# 网页可靠性与交互修复

这次修复把旧词句功能与 Codex 学习 API 的可靠性规则统一：同一账号、同一写入编号、保存确认后再显示完成。

## 数据约束

- 当前账号只能读取自己的缓存和队列；账号切换当次渲染就隐藏旧账号内容，过期请求不得更新当前界面。
- 新增先保存稳定 UUID 和完整请求；未知回执重试同一个请求，不生成第二条记录。
- 云端快照与本地待新增、待删除和待更新合并显示；较旧读取结果不能覆盖刚确认的写入。
- 临时网络、限流、服务故障仍可重试。明确失败不隐藏，用户可查看状态、导出并决定重试或放弃。
- 未发送的删除可取消；已尝试的删除和恢复按依赖顺序完成。恢复失败保留操作入口。
- 旧版无归属缓存保留为隔离备份；新缓存清理不删除待同步队列。
- 句子保留原文、翻译、重点词、语法、来源及时间；服务端收据阻止旧请求复活已删除句子。
- 学习 API 的登录读取、请求和响应解析共享 15 秒期限；超时保留原请求以便重试，后台刷新不遮住已缓存词表。

## 交互约束

- 新增失败保留输入；“已保存”“已恢复”只对应确认结果，离线持久化明确显示待同步。
- 保存期间锁定当前草稿，扩展词复选框只切换一次；用户不会因旧请求完成而丢掉新编辑。
- 编辑句子原文会更新保存目标并清除已失效的分析。
- 评分和撤销等待持久化结果，失败后可以重试，重复点击不重复提交。
- 复习卡支持键盘翻面；不可见面不进入辅助技术焦点顺序；图标按钮有名称。
- 虚拟词库按照实际页面偏移定位，布局变化重新测量；长词和长释义可以换行。
- 设置独立为抽屉，支持焦点约束、Escape、关闭后恢复焦点，手机页面不再被整块设置推长。
- 网页 AI 配置在相关功能旁提示；手动输入和 Codex 练习可以直接使用。“今日”明确为“今日新增”。

## 验收范围

回归检查覆盖双账号切换、旧缓存迁移、断网、五次以上临时失败后的恢复、未知回执、待同步内容合并、删除与撤销竞争、磁盘写入失败、句子编辑、手机长词、滚动定位和键盘交互。依赖升级分提交检查类型、测试、构建与审计，并在最终版本重新验证 Vercel 函数、线上 API 与 PWA。
